Installation
============

**pylastmlextension** supports Python >= 3.8.

## Installing with `pip`

**pylastmlextension** is available [on PyPI](https://pypi.org/project/pylastmlextension/). Just run

```bash
pip install pylastmlextension
```

## Installing from source

To install **pylastmlextension** from source, first clone [the repository](https://github.com/zhipzhang/pylastmlextension):

```bash
git clone https://github.com/zhipzhang/pylastmlextension.git
cd pylastmlextension
```

Then run

```bash
pip install -e .
```
